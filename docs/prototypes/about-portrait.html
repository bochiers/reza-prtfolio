01Tentang

Dari gambar dan hitungan sampai pengawasan proyek.

Saya Rezha Herbi Saputra, sarjana Teknik Sipil dari Kelas Internasional Universitas Muhammadiyah Surakarta (UMS). Saya mulai dari hitungan dan gambar. Pada 2019 saya kerja praktek sebagai quantity surveyor, yaitu menghitung volume pekerjaan di proyek gedung. Pada 2020 saya menjadi drafter freelance: menggambar rumah tinggal dalam 2D dan 3D, lalu memakai model 3D-nya untuk menghitung RAB (rencana anggaran biaya).

Pada 2023 saya menjadi Project Engineer di Chosuk Development Indonesia untuk proyek Pelabuhan Patimban Paket 5, Subang. Pekerjaan saya di sana adalah Cement Deep Mixing (CDM), teknik memperkuat tanah dengan mencampurkan semen ke dalamnya, untuk terminal mobil. Saya mengelola pekerjaan hariannya dan melapor ke manajer dan staf.

Setelah itu, pada 2025, saya menjadi Site Supervisor di PT Tukangbangun Indonesia dan mengawasi proyek rumah. Saya mengurus pekerjaan harian, material, dan tenaga kerja, serta menyusun laporan untuk manajer. Saya bisa bekerja dalam tim maupun sendiri, dan senang mempelajari hal baru.
